# 현재 구현 상태

기준일: 2026-10-13

공유판은 자기 Git 프로젝트를 연결하고 Lead → Builder → Verifier로 조사·구현·검증하는 플랫폼이다.

- 프로젝트 이름·목적·참고 자료·빌드/검증 안내를 등록하고 작업에 고정한다.
- 프로젝트 소스를 격리된 Git 작업공간에 복사한다. 원본 프로젝트를 자동으로 병합하거나 배포하지 않는다.
- 로컬 Codex CLI의 모델과 역할별 추론 강도를 선택한다.
- 역할별 메시지, 사용자 질문·피드백, 구현 파일과 결과를 웹에서 확인한다.
- 개발 메모·자료·파일 해시·검증 내용을 프로젝트별 지식 저장소에 자동 적재한다. 재시작 후 누락 기록을 따라잡는다.
- 지식맵에서 프로젝트/주제별 탐색, 전체 본문 검색, 코드·참고 자료·저장 결과·근거 상세를 제공한다.
- 필요하면 Cloudflare 릴레이로 원격 화면과 지식 기록을 동기화한다. 계정 설정은 설치별로 준비한다.

내장 보드 등록·연결·업로드·스코프 실행, 계약/Campaign 실행기, 과거 연구실 예제와 문서는 공유판에서 제외한다.
새 프로젝트에 필요한 개발 도구와 외부 서비스는 프로젝트 안내에 명시한다.

검증 결과는 저장소 루트 README의 검증 항목에 기록한다. 실제 유료 모델·실장비 검증과 모의 모델 회귀 검증을 구분한다.

검증: 필요한 파일만 담은 별도 설치에서 Python 회귀 339개를 검사했고 마지막 수정 영향 22개를 재검증했다.
프런트엔드 140개, Cloudflare 지식 동기화 3개, TypeScript/Vite 빌드, Python compile,
독립 데몬 dry-run 시작·종료와 PowerShell 실행기 구문 검사를 통과했다.
실제 유료 모델·장비는 호출하지 않았다. Windows Git 파일 목록 조회의 무기한 대기를 발견해
작업공간 Git 명령에 60초 시간 제한을 추가했다.
